# 🎓 Unify

> A modern all-in-one student productivity platform designed to simplify university life.

Unify is a full-stack web application built to help university students manage their academic and campus life from a single dashboard. It aims to combine productivity, organization, and collaboration into one clean, intuitive platform.

---

## ✨ Vision

Instead of juggling multiple apps and websites, students can use Unify to:

- 📅 Manage class schedules
- ✅ Track assignments and deadlines
- 📈 Calculate GPA and CGPA
- 📚 Organize study notes
- 📢 Stay updated with campus announcements
- 🎉 Discover university events
- 👤 Manage their academic profile

The project is being developed as a semester-long full-stack web development project.

- MongoDB

### Authentication

- JSON Web Tokens (JWT)

### Local authentication email setup

Set the backend variables documented in `backend/.env.example`. Email verification and
password-reset links use `APP_BASE_URL` when present, otherwise `CLIENT_ORIGIN`. Configure
`RESEND_API_KEY` and an `EMAIL_FROM` sender verified in Resend before testing delivery.
